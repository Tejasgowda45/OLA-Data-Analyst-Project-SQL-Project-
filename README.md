* Analyzed 20,400+ Ola ride bookings using MySQL to identify trends in cancellations, customer ratings, payment methods, and revenue across vehicle types using aggregations, Top-N queries, and window functions.
* Identified a 17.9% driver cancellation rate versus 10.2% customer cancellation rate and found that Cash generated the highest successful ride revenue (₹38.2L), followed by UPI (₹27.6L).
* Created 10 reusable SQL views for core business questions and developed cancellation-rate and revenue-ranking analyses by vehicle type, enabling efficient retrieval of key performance indicators (KPIs).
